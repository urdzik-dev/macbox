# Чекліст ручної live-перевірки (MacBox)

> Юніт-тести перевіряють протокол, кодування, координати й схеми, але **не доводять**, що реальна гостьова macOS завантажується й керується. Цей чекліст заповнюється по мірі проходження фаз.

## Фаза 1 — Spike (VM у вікні)
- [x] Бінарник `macbox` підписаний з `com.apple.security.virtualization`
- [x] `macbox doctor` коректно діагностує Apple Silicon, macOS 14+, entitlement і вільне місце на диску
- [x] Створення sparse-диска та завантаження/підключення IPSW (`VZMacOSRestoreImage`)
- [x] Встановлення macOS у VM завершується без помилок
- [ ] VM запускається з коду, робочий стіл/Setup Assistant відображається в нативному вікні `VZVirtualMachineView`

## Фаза 2 — Транспорт і кадри (бенчмарк)
- [ ] Перевірено `vsock` (`AF_VSOCK`) у реальному macOS-гості (працює / обмеження)
- [ ] Перевірено `virtio-fs` (`macOSGuestAutomountTag`) у реальному macOS-гості
- [ ] Перевірено `virtio-console` у реальному macOS-гості
- [ ] Заміряно RTT (1 KiB) і передачу кадру (1 MiB) для робочих кандидатів + NAT TCP
- [ ] Таблиця вимірів занесена в `DECISIONS.md`, обрано фінальний транспорт і формат кадрів

## Фаза 3 — Ввід без впливу на хост
- [ ] `MacBoxAgent.app` відмовляється запускатися на хості (не `VirtualMac`)
- [ ] `MacBoxAgent.app` працює у гості після надання Screen Recording + Accessibility
- [ ] Тестовий скрипт робить скріншот, клікає по іконці в Dock і друкує текст у TextEdit
- [ ] Під час роботи скрипта користувач вільно рухає мишею та друкує на хості без конфліктів

## Фаза 4 — Viewer у терміналі
- [ ] Плавне відображення в Ghostty / Kitty (перевірити SHM `t=s`)
- [ ] Плавне відображення в iTerm2 (OSC 1337)
- [ ] Ресайз вікна терміналу коректно перемасштабовує кадр зі збереженням пропорцій
- [ ] У простої CPU мінімальний, після виходу viewer стрім зупиняється

## Фаза 5 — Інтерактивний режим
- [ ] Набір тексту, стрілки, спецклавіші
- [ ] Лівий/правий клік, подвійний/потрійний клік, drag, scroll
- [ ] `Ctrl+G` палітра Mac-шорткатів (Spotlight, Copy/Paste, Mission Control)
- [ ] `Ctrl+]` чисто виходить із viewer, VM продовжує працювати

## Фаза 6 — MCP-сервер і Skill
- [ ] Claude Code підключається до `macbox mcp` через stdio
- [ ] Агент самостійно відкриває Safari у VM, виконує пошук і повертає скріншот
- [ ] Координати кліків точно збігаються з координатами на скріншоті (HiDPI 2x і standard 1x)

## Фаза 7 — Власні доповнення
- [ ] `macbox clone` клонує VM через APFS `clonefile` (< 200 ms, незалежний `VZMacMachineIdentifier`)
- [ ] `macbox snapshot save` / `restore` відновлює пам'ять і диск
- [ ] `ax_tree` повертає валідне дерево елементів активного вікна з координатами в системі скріншота
